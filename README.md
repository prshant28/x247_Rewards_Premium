## ◈ Overview

<table>
<tr>
<td width="50%">

**X247 Rewards Premium** is a full-stack, ultra-premium giveaway and rewards platform engineered to deliver an unmatched dark-aesthetic experience. Built as a pnpm monorepo with a React + Vite frontend and an Express 5 API backend, it combines bleeding-edge UI with robust contest management, a sophisticated referral engine, and AI-powered interactions.

The platform is built on a **pure black monochrome design system** — no color accents, no compromise — with WebGL silk backgrounds, rotating gradient-border glass cards, magnetic cursor effects, and buttery Framer Motion animations.

## ◈ Theme System

The platform ships with **9 hand-crafted themes** — zero config, instant switch:

<div align="center">

```
DARK THEMES                          LIGHT THEMES
────────────────────────────────     ────────────────────────────
  ◈ Metallic Glass  (default)          ◈ Pristine Light
  ◈ Frosted Aurora                     ◈ Ivory Soft
  ◈ Brushed Steel                      ◈ Silver Mist
  ◈ Smoky Glass
  ◈ Noir Minimal
  ◈ Liquid Dark
```

</div>

Themes are managed by `ThemeContext` and persisted via `localStorage` under the key `x247_theme`. A flash-prevention inline script in `index.html` pre-applies the stored theme before React hydrates, eliminating FOUC.

**CSS Architecture:** 30+ custom `--x-*` CSS properties control every theme-sensitive value — nav glass, hero gradients, dot grid colors, card fills, chat bubbles, badge tints, and more.

## ◈ Database Schema

<div align="center">

```
users ──────────┬── user_sessions
                ├── giveaway_entries
                ├── notifications
                ├── push_subscriptions
                ├── notification_preferences
                └── referral_conversions

partners ───────┬── clicks
                ├── impressions
                └── form_fills

referral_partners ─── referral_clicks
                   └── referral_conversions

admin_users ────── admin_sessions

contests ────────── (linked to giveaway_entries)

conversations ────── messages

winners
```

</div>

**ORM:** Drizzle ORM with type-safe queries and schema-driven Zod validators (`drizzle-zod`). API types auto-generated via Orval from the OpenAPI spec.

## ◈ Getting Started

### Prerequisites

```bash
node  >= 24
pnpm  >= 9
postgresql >= 15
```

### Installation

```bash
# Clone the repository
git clone https://github.com/prshant28/x247_Rewards_Premium.git
cd x247_Rewards_Premium

# Install all workspace dependencies
pnpm install
```

### Development

```bash
# Start the API server
pnpm --filter api-server dev

# Start the frontend (in a separate terminal)
pnpm --filter x247-rewards dev
```

### Build

```bash
# Typecheck entire workspace
pnpm typecheck

# Build all packages
pnpm build
```

## ◈ Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```env
# ── Database ──────────────────────────────────────────────────
DATABASE_URL=postgresql://user:password@localhost:5432/x247

# ── Auth ──────────────────────────────────────────────────────
SESSION_SECRET=your_session_secret_here

# ── AI / Chatbot ───────────────────────────────────────────────
OPENROUTER_API_KEY=your_openrouter_key

# ── Text-to-Speech ─────────────────────────────────────────────
ELEVENLABS_API_KEY=your_elevenlabs_key

# ── Notifications (VAPID) ─────────────────────────────────────
VAPID_PUBLIC_KEY=your_vapid_public_key
VAPID_PRIVATE_KEY=your_vapid_private_key
VAPID_SUBJECT=mailto:admin@x247rewards.com

# ── Captcha ────────────────────────────────────────────────────
HCAPTCHA_SECRET_KEY=your_hcaptcha_secret
```
